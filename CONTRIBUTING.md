# Contributing to Today Agent Learned

Thanks for sharing what you've learned! Here's how to contribute.

## Guidelines

### What makes a good TAL?

- **One thing per entry.** If you learned two things, write two TALs.
- **Under 200 words.** Be ruthless. Cut the preamble.
- **Include a working example.** Code, commands, config — something copy-pasteable.
- **Specific > generic.** "Use temperature 0 for JSON extraction" beats "prompt engineering tips."
- **Failures count.** "X doesn't work because Y" saves people real time.

### What doesn't belong?

- Full tutorials or walkthroughs (write a blog post instead)
- Product announcements or news
- Opinions without a concrete takeaway
- Anything requiring more than 2 minutes to read

## How to Submit

1. Fork the repo
2. Create `category-folder/your-tal-title-as-slug.md`
3. Use [TEMPLATE.md](TEMPLATE.md) as your starting point
4. Add your entry to the table of contents in `README.md`
5. Open a PR with a one-line description of what you learned

## File Naming

Use lowercase kebab-case: `use-xml-tags-for-structure.md`

The filename should read like a compressed version of the insight.

## Categories

If your TAL doesn't fit existing categories, propose a new one in your PR.

## Code of Conduct

Be helpful, be honest, be kind. We're all learning.
